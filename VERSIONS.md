# Версии игры

Каждая сохранённая версия лежит в отдельной ветке, которую больше никто не меняет.
Чтобы вернуться, скажите «откати на версию N».

## Версия 1 (ветка `v1`, коммит `c897084`)

Мультяшная графика в стиле референса, механика исходной игры без изменений:
6 типов юнитов, карты улучшений каждые 20 секунд, ИИ-противник, лучники на стенах замков,
стартовый экран, статистика боя, адаптация под телефон. Публикация на GitHub Pages включена.

Посмотреть: https://github.com/vvvq3/ClaudeWork1/tree/v1

### Как откатиться без потери истории

```bash
git checkout claude/busy-tesla-9efzv1
git checkout v1 -- .          # вернуть все файлы версии 1
git commit -m "Откат на версию 1"
git push origin claude/busy-tesla-9efzv1
```

Pages опубликует откатанную версию сам.
