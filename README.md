# 🏰 Битва Замков

Браузерная стратегия в реальном времени: **красные против синих**. Слева ваш замок, справа замок компьютера.
Побеждает тот, кто первым разрушит замок противника.

**▶ [Играть онлайн](https://vvvq3.github.io/ClaudeWork1/)**

## Как играть

- 🪙 **Золото** начисляется каждую секунду (+4/сек в начале). Тратьте его на войска.
- ⚔️ **Войска** (9 типов): крестьянин, лучник, рыцарь, арбалетчик, конный рыцарь, катапульта, копейщик, маг и командир.
  Характеристики каждого видны во всплывающем хинте при наведении на карточку (на телефоне: долгое нажатие).
  - **Копейщик** наносит конным рыцарям ×2,5 урона.
  - **Маг** бросает огненные шары, каждый бьёт сразу 3 цели. Огонь игнорирует броню рыцарей и конницы и наносит катапультам ×1,5 урона.
  - **Командир** воодушевляет всю вашу армию на поле: +30% здоровья и урона и лечение 3% здоровья в секунду.
    Бонус действует, пока командир жив. Держится позади войск, несколько командиров не складываются.
- 🃏 **Карты улучшений**: каждые 20 секунд игра встаёт на паузу и предлагает 3 карты на выбор
  (добыча золота, скидки на найм, урон и здоровье юнитов, броня и ремонт замка, «кара врагов»).
  Противник выбирает свою карту одновременно с вами. Дополнительный выбор из 3 карт можно купить за золото.
- 🏹 На стенах каждого замка стоят 3 лучника с большой дальностью стрельбы.
- 🏰 **Улучшение замка** за 100, 200, 300, 400 и 500 золота. По очереди добавляет в гарнизон лучника, арбалетчика, мага,
  катапульту и командира. Каждое улучшение даёт замку ещё +400 здоровья. Враг тоже улучшает свой замок.
- 🛡️ Рыцари и конные рыцари получают на 50% меньше урона от стрел, болтов и камней.
- 📊 После боя показывается статистика: какой род войск нанёс больше всего урона.

### Управление

| Клавиша | Действие |
| --- | --- |
| `1`–`9` | нанять: крестьянина, лучника, рыцаря, арбалетчика, всадника, катапульту, копейщика, мага, командира |
| `0` | купить дополнительные 3 карты улучшений |
| `-` | улучшить замок |
| `Пробел` | пауза |

Карты улучшений выбираются только мышью, чтобы случайно не нажать цифру во время боя.

## Запуск

Сборка не нужна: готовый CSS лежит в репозитории. Достаточно раздать папку статическим сервером:

```bash
npm start
```

и открыть http://localhost:8000. Можно и просто открыть `index.html` в браузере.

## Графика

Вся графика нарисована кодом на Canvas, внешних картинок нет. Стиль: толстый тёмный контур, ячеистая заливка, крупные головы.

- **Юниты** анимируются «скелетно»: походка, замах и удар оружием, натяжение лука и арбалета, галоп коня, взвод катапульты.
  Каждый кадр один раз отрисовывается в спрайт и дальше просто копируется (`drawImage`), поэтому сотни юнитов не тормозят.
- **Замки** (башни с конусными крышами, ворота, зубцы, лучники на стене) рисуются в кэш. По мере разрушения на них появляются
  трещины, дыры, дым и огонь. Флаги развеваются в реальном времени.
- **Сцена**: небо с облаками, холмы, деревья, кусты, цветы и песчаная дорога. Фон пересобирается при изменении размера окна,
  картинка чёткая на экранах с высокой плотностью пикселей.
- **Эффекты**: звёздные вспышки при ударах, искры, облачка пыли, следы стрел, камни и обломки катапульты,
  звёздочки при падении юнита, огненные шары мага, молнии карты «Кара врагов», числа урона.
- **Интерфейс**: деревянные панели, компактные карточки с названием, портретом и ценой, всплывающие хинты с характеристиками, адаптация под телефон.

## Структура проекта

```
index.html            разметка: HUD, нижняя панель юнитов, модальные окна, стартовый экран
css/styles.css        стили интерфейса (деревянные панели, карточки, полоски здоровья)
css/tailwind.css      собранный Tailwind (генерируется, см. ниже)
js/audio.js           синтезатор звуков на Web Audio
js/units.js           характеристики юнитов (9 типов) и тексты для хинтов
js/state.js           состояние игры и константы (экономика, интервалы, места и цены улучшений замка)
js/upgrades.js        генерация и применение карт улучшений
js/ui.js              нижняя панель, HUD, окно выбора карт
js/ai.js              поведение компьютерного противника: покупки, ответ на конницу, улучшение замка
js/battle.js          спавн, движение, бой, снаряды, гарнизон замка, аура командира
js/gameover.js        экран победы и поражения со статистикой
js/render.js          сборка кадра: фон, замки, юниты, снаряды, эффекты
js/main.js            игровой цикл, горячие клавиши, старт и перезапуск
js/art/util.js        палитры, контуры, вспомогательные функции рисования
js/art/units-infantry.js   крестьянин, копейщик, рыцарь, лучник, арбалетчик, маг, командир
js/art/units-heavy.js      конный рыцарь и катапульта
js/art/units.js       позы из состояния игры, кэш спрайтов, падение юнитов, портреты
js/art/castle.js      замок: кэш по уровням разрушения, флаги, дым, огонь
js/art/scene.js       небо, облака, холмы, деревья, дорога
js/art/fx.js          частицы, вспышки, следы снарядов, числа урона, молнии
js/art/icons.js       иконки карточек улучшений и портреты юнитов
dev/gallery.html      галерея всех юнитов во всех позах (для разработки)
```

Скрипты подключаются обычными `<script>` по порядку и делят общее глобальное состояние (`gameState`).
Игровая логика и графика разделены: графика читает состояние, но ничего в нём не меняет, кроме визуальных эффектов.

## Разработка

Стили Tailwind собираются из классов, которые встречаются в `index.html` и `js/`. После правки классов пересоберите CSS:

```bash
npm install
npm run build:css
```

Для автоматической пересборки используйте `npm run watch:css`.

Чтобы посмотреть юнитов крупно, запустите `npm start` и откройте http://localhost:8000/dev/gallery.html.
Там все девять юнитов обоих цветов показаны в походке, в позе готовности, в замахе и в ударе.

## Настройка баланса

Основные числа лежат в `js/units.js` (цена, здоровье, урон, скорость и дальность юнитов) и `js/state.js`
(интервал карт `UPGRADE_INTERVAL`, скорость начисления золота `GOLD_TICK_INTERVAL`, цены и награды улучшений замка `CASTLE_UPGRADES`,
прибавка здоровья `CASTLE_UPGRADE_HP`). Аура командира настраивается в его описании в `js/units.js` (поле `aura`).
