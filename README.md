# Крестики-нолики

Простая браузерная игра в крестики-нолики. Один файл `index.html`, без сборки и зависимостей.

## Возможности

- Игра с компьютером (уровни «Легко» и «Непобедимый» на алгоритме минимакс) или вдвоём на одном устройстве.
- Счёт побед и ничьих, первый ход чередуется между партиями.
- Светлая и тёмная тема, адаптивная вёрстка для телефона.

## Запуск

Откройте `index.html` в браузере. Либо запустите локальный сервер:

```bash
python3 -m http.server 8000
```

и перейдите на http://localhost:8000.
